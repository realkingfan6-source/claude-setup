name: grill-me
description: Stress-test a plan before building it. Fires on its own at the start of any big feature, rebuild, new game system, channel or product direction, or a plan with open choices (J rule: big work = plan first); also when J says "grill me". Interviews J one branch at a time with a recommended answer each, explores the code instead of asking where it can, stops at shared understanding. Not for small fixes or when J already decided.
---

Interview me relentlessly about every aspect of this plan until we reach a shared understanding. Walk down each branch of the design tree, resolving dependencies between decisions one-by-one. For each question, provide your recommended answer.

If a question can be answered by exploring the codebase, explore the codebase instead.

(Source: brianlovin/claude-config, skills/grill-me, installed 2026-10-12 at J's request. J's house rule: ask one question at a time with AskUserQuestion where it fits, recommended answer first; stop when every branch is resolved and write the result into the project's plan doc.)
